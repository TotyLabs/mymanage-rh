# Business Documentation - MyManageRH

## 1. Propósito

La carpeta `business/` contiene documentación corporativa, marcaria y societaria relacionada con TotyLabs y MyManageRH.

Esta carpeta no debe usarse para almacenar secretos, documentos legales firmados con datos sensibles, credenciales, recibos reales, documentación bancaria, llaves privadas ni información personal de socios o empleados si el repositorio no es privado y con acceso restringido.

## 2. Documentos incluidos

| Documento | Uso |
| --- | --- |
| `MARCA_INPI.md` | Seguimiento del registro marcario MyManageRH ante INPI. |
| `ESTATUTOS.md` | Información societaria base de TotyLabs y relación con MyManageRH. |

## 3. Qué no debe subirse al repo público

- Estatutos firmados completos con datos personales sensibles.
- DNI, domicilios reales o información patrimonial de socios.
- Constancias fiscales privadas.
- Contratos firmados con clientes.
- Comprobantes bancarios.
- Certificados privados, llaves, P12 o passwords.
- Documentos INPI con datos sensibles no redactados.
- Recibos de sueldo reales.
- Dumps de base de datos.

## 4. Archivos que deben mantenerse privados

- Contratos enterprise.
- Cap table o documentación de inversión.
- Poderes, actas y resoluciones societarias.
- Certificados legales originales.
- Evidencia de marca con datos no públicos.
- Documentación de auditoría con hallazgos sensibles.
- Políticas internas de seguridad no publicables.

## 5. Recomendación de control de acceso

- Mantener este repositorio privado si contiene documentación operativa real.
- Usar permisos por rol: legal, dirección, seguridad, ingeniería.
- Redactar datos personales antes de versionar documentos.
- Separar repositorio público de documentación comercial del repositorio operativo.
- Revisar accesos trimestralmente.
- Activar protección de ramas y revisión obligatoria para cambios legales o de seguridad.

## 6. Responsable sugerido

| Área | Responsable |
| --- | --- |
